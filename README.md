# LiveFrame

### 把视频里喜欢的一小段，做成实况照片。

烟花散场之后，照片里的光还可以继续亮着。

LiveFrame 帮你从视频里留下那几秒。封面选哪一帧、画面留住谁、要不要签上名字，都由你决定。

## 好看的几秒，值得单独留下

拍视频的时候，我们常常会多录一会儿。真正喜欢的，也许只是烟花刚升起来的那一刻，或朋友转头笑的那几秒。

把视频放进 LiveFrame，找到这一段，就能做成手机里的实况照片。你可以为它重新选一张封面，把横屏画面调整成适合手机看的竖屏，再放上自己的署名。导出时选择 Android 或 iOS，软件会生成对应的实况照片文件。

编辑界面分成三个页面。按顺序做很顺手，想先看封面、最后再调时长，也完全可以。不需要的步骤可以跳过，觉得画面已经足够好看，直接导出就行。

## 先找到你想留下的那一段

长视频也不用来回猜。放大时间轴，画面就能一帧一帧地看；找到大致位置后，拖动开始和结束手柄，预览会跟着显示手柄所在的那一帧。想精确到某个时间，也可以直接输入秒数。

<img src="assets/duration.png" alt="时长范围页面，微信模板将输出时长锁定为 3.97 秒。" width="100%">

选了模板之后，时长会先锁住。比如要做一张 3.97 秒的朋友圈实况，你只管在视频里寻找最合适的内容。拖首帧、拖尾帧，整段都会跟着移动，长度始终保持一致。需要多留一会儿，或者想让两个端点分别调整，再把锁定关掉。

倍速也跟着这个思路走。3 秒的作品开到 2 倍速，就能装下 6 秒的原视频；调到 0.5 倍速，则把 1.5 秒的动作慢慢展开。速度可以在 0.5 到 3 倍之间调整，声音可以保留，也可以关掉。

时间轴支持滚轮平移和触控板捏合缩放。「全片」方便找位置，「选区」方便看细节；播放头可以跟随画面移动，拖动手柄到边缘时，时间轴会继续向前或向后滚动。三个编辑页面共用这一条时间轴，切换页面不用重新找位置。

## 让封面停在最好看的一帧

实况照片没动起来之前，封面就是别人看到的第一眼。我们给它留了一块足够大的预览区域，方便看清表情、光线和画面里的小细节。

<img src="assets/cover.png" alt="设定封面页面，可以从视频中精确选帧，也可以选择自己的图片。" width="100%">

你可以从视频里逐帧挑选，用正在播放的那一帧作为封面，或者直接放入自己选好的图片。预览还能继续放大，方便确认细节。

### 横屏转竖屏，主角不必站在正中间

拍摄时用横屏，发布时想用竖屏，这时候最怕的就是裁掉了真正想留的内容。

选择「裁切构图」，预览里会出现一个跟随模板比例的框。框外的画面变暗，但仍然看得见。按住框内空白处或边框拖动，就能把取景范围移到你想要的位置。小红书全屏模板的框保持 3:5，横屏素材可以左右选，竖屏素材则能上下调整。

<img src="assets/framing.png" alt="3:5 构图框向左移动，框外的原始画面仍然可见。" width="100%">

封面页和水印页共用这个位置，导出也按同一位置取景。调整之后想重新来，一键就能回到居中。想保留整个画面，则选择「完整画面」，用黑边补齐输出比例。

## 给作品签个名

可以是一行小小的署名，也可以是自己的 Logo。文字和图片都能放进来，还可以叠加多个图层。按住水印本体拖动，就能把署名放在合适的位置。

<img src="assets/watermark.png" alt="水印叠加在封面上，右侧可调整混合方式和阴影。" width="100%">

文字水印会读取 Mac 当前可用的全部字体和字重样式。选字体时可以搜索，也能看到实际预览；文字支持换行，字号、颜色和描边都能调整。图片水印支持透明 PNG，放上去就能保留 Logo 原来的透明边缘。

觉得水印太抢眼，可以降低不透明度，或换一种混合方式。想让它从背景里稍微浮出来，就加一点阴影。大小、旋转和位置都可以细调；每层还可以分别决定，是只出现在封面上，还是也跟着视频一起播放。

| 可调的内容 | 具体功能 |
| :--- | :--- |
| 字体与文字 | 系统字体搜索与预览、多行文字、字号、颜色、描边 |
| 大小与位置 | 缩放、直接拖动、横纵百分比定位、九宫格定位、旋转 |
| 混合方式 | 正常、正片叠底、滤色、叠加、柔光、强光、变暗、变亮、差值、排除 |
| 阴影 | 颜色、柔化、浓度、横纵偏移 |
| 图层 | 最多 12 层，支持复制、排序、显示、隐藏和删除 |
| 显示范围 | 只在封面显示、只在视频显示，或两者都显示 |

新建水印默认使用「叠加」。你可以切换「静态封面」和「动态视频」，先看看它压在封面上是否合适，再播放一遍，确认它在移动的画面里也舒服。构图调整后，水印仍然保持在最终画幅里设定的位置。

## 做好之后，带到你的手机里

左上角的 LiveFrame Logo 也是切换入口。点一下，就能在 Android 和 iOS 之间切换。Android 用青绿和暖金，iOS 用蓝紫和粉色，打开界面就能看出当前选的是哪一种。

<img src="assets/ios.png" alt="切换到 iOS 后，界面使用蓝紫配色，导出按钮对应 Apple Live Photo。" width="100%">

切换手机模式时，刚才编辑好的片段和画面都会保留，导出的文件格式随之改变。

**Android 会得到一个动态 JPG。** 封面和 MP4 视频装在同一个文件里，传原文件就能把两部分一起带过去。通过文件传输保存到手机的 `Pictures` 或 `DCIM`，在相册里查看。

**iOS 会得到配对的 JPG 和 MOV。** 导出完成后，点击「保存到照片」，就可以把它作为一个 Live Photo 放进 Mac 的照片图库，再通过 iCloud 照片同步到 iPhone。

传到手机时，使用文件传输保留原件，让封面和动态画面一起到达。

## 常用的发布尺寸，我们先帮你设好

朋友圈和小红书常用的几种画幅都放进了模板里。选中之后，尺寸和时长一起应用，接下来专心选画面就好。

<img src="assets/export.png" alt="导出设置页面，可选择发布模板，并调整输出分辨率和编码设置。" width="100%">

| 模板 | 比例 | 分辨率 | 输出时长 |
| :--- | :---: | :---: | :---: |
| 微信朋友圈横屏 | 16:9 | 1920 × 1080 | 3.97 秒 |
| 微信朋友圈方形 | 1:1 | 1440 × 1440 | 3.97 秒 |
| 微信朋友圈竖屏 | 2:3 | 1280 × 1920 | 3.97 秒 |
| 小红书横屏 | 16:9 | 1920 × 1080 | 10 秒 |
| 小红书方形 | 1:1 | 1440 × 1440 | 10 秒 |
| 小红书竖屏 | 2:3 | 1280 × 1920 | 10 秒 |
| 小红书竖屏全屏 | 3:5 | 1536 × 2560 | 10 秒 |

同一个模板可以在 Android 和 iOS 两种模式下使用。选好画幅，再选择你的手机，导出就按对应的格式完成。

也可以自己设置尺寸。原始、720p、1080p 和 4K 都有现成选项，自定义宽高支持 16–8192 范围内的偶数；帧率可以选 24、25、30 或 60 fps。需要普通视频时可以导出 MOV，想做循环动图则可以导出 GIF。Instagram 预设用于准备构图素材，动态发布可以使用视频。

## 在 Mac 上慢慢做，视频也留在这里

素材处理都在本机完成，源视频保持原样，导出会生成新的文件。使用 LiveFrame 不需要注册账号，也不用先把视频上传到服务器。

界面的颜色取自阳光穿过玻璃时的折射。在 macOS 26 及以上，导航和控制区域融入系统 Liquid Glass。大图预览和右侧设置面板保持固定的位置，来回切换三个页面，操作习惯也跟着保留下来。

## 装好以后，导入视频就能开始

[下载 Mac 安装包](https://github.com/ARCHIC001/LiveFrame/releases/download/v2.4.1/LiveFrame-2.4.1-macOS-arm64.dmg)，打开后将 LiveFrame 拖入「应用程序」。导入你的视频，找到喜欢的那一段，就可以开始制作。

适用于 **Apple 芯片 Mac，macOS 13 及以上**。[查看安装方法](INSTALL.md)。
